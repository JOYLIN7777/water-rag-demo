模型配置

统一配置对话模型与向量模型，兼容公有云 API 与内网私有部署的 OpenAI 兼容端点。

模型可插拔：公有云（DashScope / DeepSeek）与内网私有部署（vLLM / Ollama / Xinference 等 OpenAI 兼容接口）统一配置。 Chat 模型切换即时生效；Embedding 模型切换前会校验向量维度，必须与现有向量库一致，否则拒绝切换以免污染已入库数据。 API Key 只回显前 4 后 4，更新时不填即保持原值。
