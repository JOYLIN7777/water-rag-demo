问答文档检索模型
pi-mono 风格会话模型：每条消息都记住自己的父节点，因此一个会话可以长出多条分支。 rewind 只把当前位置移回旧节点，不删除任何消息；fork 从旧节点开新支继续提问， 旧分支完整保留。上下文只取当前节点到根这条链，兄弟分支不会串进回答。 注意：工具副作用（如外部 API 调用）不会随 rewind 回滚，这里回滚的只是对话上下文。
